EventHub – Event Registration Management System is a full-stack web application that lets users discover and register for events, and lets admins manage those events end to end.
Users can sign up, log in, browse events by type or search, view details (capacity, seats, deadline), and register individually or as a team. Names are validated and duplicate registrations for the same event are blocked. Users can also view and cancel their own registrations.
Admins have a separate login and dashboard with statistics (users, events, registrations, event types). They can add, edit, close, or delete events, set team size, view all registrations, and access reports such as registrations by event/type and most popular events.
The system is built with Python and Flask for all business logic, SQLite for data storage, and HTML/CSS with minimal JavaScript for the interface. Features include password hashing, session-based auth, flash messages, automatic expiry of past deadlines, and a dark professional UI with a sliding landing page.
